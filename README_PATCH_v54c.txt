SimDron Web v5.4c — Perspectives / Mission Control / Preset Tuning

CAMBIOS
1. Cartografía:
   - Se mantiene el mapa 2D.
   - Se muestra a su lado una vista 3D/perspectiva.
   - Se incorporan nuevas perspectivas para:
     Deck, Desert, Airbase, Coast, Combat, Forest, Hangar y Field.
   - Urban, Industrial, Mountain, Trench y Polygon conservan las perspectivas ya agregadas.

2. Mission Control:
   - El desplegable superior ahora presenta explícitamente dos conceptos:
     MULTI-VTX / LIVE WALL
     INSTRUCTOR / AI
   - Ambas imágenes permanecen accesibles como galería dentro del mismo panel.

3. Presets:
   - Se mantiene el selector de 16 plataformas.
   - Se agrega al lado un panel de valores de ajuste:
     Angle, Prop, Exp, Inertia, Thrust, Multiplier, Mass, Drag y Angular.
   - Los valores se presentan como ejemplo del panel de configuración,
     no como especificaciones fijas por aeronave.
