PÁGINA 101 Controlador

Controlador

Es el objeto principal que tiene el usuario para interactuar dentro del entorno inmersivo Este comprende un gran sistema de interfaz de usuario (UI) que muestra la cámara y datos del dron así como los diferentes elementos de UI para configuración

Inicialmente este aparece enfrente del usuario, listo para ser utilizado, pensado para una altura ergonómica frente a la vista y los botones y sliders al alcance cómodo de la mano. También se pensó la altura justa para que esté por encima del escritorio que se esté usando.

El display y elementos de UI fueron diseñados para verse en cualquier condición de luz ambiental dentro de la simulación incluso de noche oscura total Se puede manipular y acomodar en otras posiciones o llevarselo en la mano cuando uno se desplaza a otro lugar. Tener en cuenta que cuando se hace esto al sistema le cuesta reacomodar nuevamente la malla de interacción, por lo que puede suceder que por unos momentos no se pueda utilizar los elementos UI, en ese caso presionar la tecla B del teclado inalámbrico, mover ligeramente el control nuevamente y verificar si se puede pulsar los botones.
