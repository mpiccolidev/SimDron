PÁGINA 34 Sistema Operativo Nuevo

Sistema Operativo Nuevo

Meta ha optimizado la interfaz de usuario del sistema operativo Meta Horizon OS Si bien se mantiene el mismo concepto la apariencia es un poco distinta a la anterior, se detallan a continuación las nuevas pantallas.

Al pulsar el botón de Meta puede acceder a los paneles, acomodarlos en su espacio de entorno y si pulsa el icono de Meta acceder al menú de configuración

PÁGINA 35 Sistema Operativo Nuevo

Sistema Operativo Nuevo

El nuevo sistema de capturas y transmisión tiene un menú más simplificado con iconos Puede realizar capturas de imagen, grabación, casting a Meta Horizon o Streaming a plataformas (Facebook y YouTube)

Para capturas rápidas utilice el control derecho y mantenga presionando el botón de Meta a la vez que dispara las capturas con el botón de Trigger (dedo índice) Cuando realiza videoshots (grabaciones) se abrirá una barra adicional flotante para indicar la configuración como incluir micrófono, tipo de vista, relación de aspecto, frecuencia, resolución y quedará flotando en pantalla la barra

PÁGINA 36 Sistema Operativo Nuevo

Sistema Operativo Nuevo

El panel de aplicaciones ha cambiado su diseño, para ver más opciones de la aplicación ahora debe mantener presionado el icono hasta que aparezca el menú Actualice la aplicación siempre que esté disponible una nueva versión

Cuando se esté descargando la actualización se indicará el porcentaje en MB Para cerrar la aplicación mantenga con sus manos el icono de Meta cuando usa hand tracking o el botón de Meta del control derecho
