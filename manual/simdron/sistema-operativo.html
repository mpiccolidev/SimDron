PÁGINA 26 Sistema Operativo

Sistema Operativo

Hay dos tipos de actualizaciones que son necesarias. Para esto es siempre conveniente conectar el Meta Quest a una red WiFi preferiblemente sin restricciones. La actualización de sistema operativo mantiene el sistema modernizado, Meta tiene una política de actualización permanente, algo que proporciona mejorías a medida que la tecnología avanza sin necesidad de cambiar el hardware tan rápido. Además esto constituye una capa de seguridad adicional. Generalmente al apagar el dispositivo le preguntará si desea actualizar, siempre aceptar. Nota: no dejar sin carga la batería mientras se actualiza.

Las actualizaciones de SimDron son menos frecuentes pero se dará aviso de las mismas, indicando los cambios en el sistema. Si hay una actualización disponible aparecerá un punto azul en la esquina superior derecha de la aplicación. Al presionar allí se despliega la ventana de opciones y seleccionar actualizar. En Ver detalles se puede ver la información del desarrollador y la versión.

PÁGINA 28 Sistema Operativo

Sistema Operativo

Los visores Meta Quest cuentan con sensores de profundidad que escanean la sala donde se utilizarán para definir un área de trabajo virtual segura en la que no corra riesgos de tropezarse o golpearse contra otros objetos.

En Menú → se puede establecer un límite sencillo fijo, ideal para cuando se trabaja sentado como es el caso de SimDron o un límite expandido de hasta 3x3 metros o indefinido de acuerdo a las consideraciones de seguridad personal de cada institución

Este sistema permite mediante Spatial Anchor definir obstáculos como mesas, pantallas, escritorios, sillas, puertas, paredes, etc. y almacenar la configuración de sala.
