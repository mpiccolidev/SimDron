PÁGINA 96 Interacciones por teclado

Interacciones por teclado

Gracias al teclado bluetooth es posible utilizar otras funciones dentro de SimDron, como manipular vehículos terrestres o volver a la escena principal en caso de perderse en el mapa

L - Vuelve a escena principal

P - reinicia escena actual B - Reinicia pantalla del control

N - Activa visor nocturno NVG

V - Cambia posición de control virtual

O - HMD

R - Reacomoda el pad

F - Emite señal ECM contra drones

Reposicionamiento de usuario en zona

Funciones otros SRNT (Sistemas Remotos No Tripulados)

Y - Switch SRNT

Para UGVs: U - Avanza J - Retrocede H - Izquierda J - Derecha I - Frena

+ 0 : Regresa a inicial + 1: Zona ALFA + 2 : Zona BRAVO + 3 : Zona CHARLIE + 4 : Zona DELTA + 5 : Zona Eco + 6 : Zona Foxtrot + 7 : Zona Golf + 8 : Zona Hotel + 9 : Zona India Al estar detenido la tecla I deja o sube cargas/heridos

PÁGINA 97 Uso de teclado con panel de configuración

Uso de teclado con panel de configuración

Es posible utilizar el teclado para manipular los elementos de UI del panel de configuración Abrir paneles Presionar Ctrl + número 1 a 0 para los botones superiores Presional Ctrl + Shift + número 1 a 0 para los botones inferiores

Navegar dentro del panel Presionar Tab para siguiente elemento Presionar Shift + Tab para elemento anterior Presionar Space para “clic” Presionar Esc para salir del modo teclado

El elemento UI actual se identifica con un outline celeste

Sliders Para subir o bajar el valor se utilizan los botones Shift (Mayus) izquierdo y derecho

PÁGINA 98 Transportación o Teleporting

Transportación o Teleporting

Permite el desplazamiento sobre la superficie del terreno de manera lineal Si se intenta superar un obstáculo con más ángulo del que el teleporting admite es posible que la cabeza quede a mitad del suelo, en este caso presionar el botón A La rotación es recomendable no utilizarla, en cambio se recomienda girar con el cuerpo, para esto es conveniente utilizar una silla giratoria.

Adelante

Derecha Izquierda

Atrás

Rotar Correr

Saltar

Para correr mantenga presionado hacia abajo a la vez que empuja el stick Si por algún motivo queda a la altura del suelo al trasladarse pruebe saltar.

Ejemplo: Usuario posicionado dentro de una estructura en el mapa Combat Ejemplo: Usuario posicionado sobre una elevación en el mapa Mountain
