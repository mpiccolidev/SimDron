PÁGINA 158 Props

Props

Estos objetos están en los diferentes escenarios con motivo de servir como objetivos o brindar un mayor realismo, algunos de ellos están dotados de una IA básica que les permite moverse por el terreno de acuerdo a determinadas lógicas de gamificación

Estos objetos están asociados a los componentes de contramedidas electrónicas (ECM) que se ajustan desde el panel de configuración En este caso son estáticos en el terreno pero se pueden redistribuir de manera aleatoria

Cajas ECM

Este objeto tiene un sistema de IA de videojuego con máquina de estado procedural que le permite moverse por el terreno siguiendo determinados patrones, pero a su vez porta una caja ECM lo cual dificulta la operación del dron principal dependiendo del rango.

Oshkosh L-ATV

Este objeto tiene un sistema de IA de videojuego con máquina de estado procedural que le permite moverse por el terreno siguiendo determinados patrones, pero a su vez porta una caja ECM lo cual dificulta la operación del dron principal dependiendo del rango.

Pickup 4x4

Este objeto tiene un sistema de IA de videojuegos que le permite volar sobre el terreno adoptando diferentes perfiles de manera aleatoria y sirve para proporcionar mayor realismo y permitiendo el entrenamiento contra objetivos aereos

USV tipo Magura

Este objeto contiene un sistema lógico de IA de videojuegos que le permite moverse por una zona “pintada” en el terreno como agua. Su objetivo, junto con otros objetos con este sistema computacional, es añadir una capa de entrenamiento superior permitiendo el reconocimiento y ataque de blancos en movimiento impredecible para el alumno

Este objeto contiene un sistema lógico de IA de videojuegos que le permite moverse por una zona bajo un determinado terreno. Además contiene un sistema de armamento con un rango de detección que dispara contra el dron principal, actuando de esta manera como objeto enemigo.

UGV D-21 12R

Este objeto contiene un sistema lógico de IA de videojuegos que le permite moverse por una zona bajo un determinado terreno. Además contiene misiles tierra aire y un sistema de rango de detección y lanzamiento contra el dron principal, actuando de esta manera como objeto enemigo.

RBS 70

Este objeto tiene un sistema de IA de videojuegos más avanzado que le permite adoptar diferentes perfiles seleccionables para evolucionar desde merodeo sobre el terreno hasta ataque con lanzamiento de una granada contra el Rig del alumno, añadiendo no solo la imprevisibilidad sino también el estrés.

Dron Mavic

Q-UGV

Este dron terrestre cuadrúpedo también posee una IA más avanzada contra el Rig del usuario, lo cual añade estrés. A su vez su sistema de máquina de estados le permite “escapar” del dron principal lo cual añade mayor dificultad. Un modelo similar puede ser utilizado de manera similar a los otros UGV interactivos mediante teclado.

PÁGINA 160 Estos objetos estáticos se distribuyen de forma

Estos objetos estáticos se distribuyen de forma aleatoria y automática al iniciar los escenarios avanzados. Sirven para añadir mayor realismo a la escena pero además para confundir al alumno por representar la misma morfología de los otros vehículos pero al acercarse claramente se observa que están destruidos.

Terrestres destruidos

Terrestres con IA

Estos objetos portan un sistema lógico de IA de videojuegos que le permiten desplazarse por el terreno de los escenarios avanzados siguiendo determinados patrones y adoptando diferentes comportamientos según el caso. Modelos: HMMWV, LATV, M1083, 4x4, T-72, Ural, BTR-80, variantes con slats y armadura contra drones improvisada. Estáticos: M777, M224

UUV

Este objeto solo presente en el mapa Coast de manera estática aprovechando el recurso de mapa de tener un escenario tipo marítimo donde se pueda practicar el reconocimiento sobre diferentes perfiles de buques. En este caso también su función es reconocer el uso de nuevas tecnologías de drones que abarcan cualquier ámbito.

Este objeto solo presente en el mapa Coast de manera estática aprovechando el recurso de mapa de tener un escenario tipo marítimo donde se pueda practicar el reconocimiento sobre diferentes perfiles de buques.

Meko 100

Estos objetos están reducidos en polígonos para poder utilizarse en cantidad: se emplean como emjambre que acompaña al dron principal si se activan o como drones aleatorios que interactuan con el detector de drones, el arma antidrones y el reconocimiento visual del alumno en el terreno.

PÁGINA 161 Presente en el escenario Coast representa un

Presente en el escenario Coast representa un dron de patrullaje tipo marítimo sobre la cubierta de un buque. El mismo se encuentra de manera estática y el usuario puede llegar hasta esa zona caminando.

Dron VTOL marítimo

Presente en el mapa FOB este objeto tiene un sistema de IA de videojuegos que le permite volar sobre el terreno realizando diferentes maniobras y salvando los obstáculos y elevaciones del mismo. Su sonido proporciona mayor realismo al entorno y además sirve como blanco de práctica para el dron principal.

UH-60

Dron de ataque One-Way

Presente en el mapa Urban este dron del tipo One-Way (solo de ida) representa un dron en perfil de ataque sobre un área urbana, sirviendo como blanco para intentar su intercepción por parte de drones de alta velocidad y FPV. Tiene un sistema de IA de videojuegos que le permite volar sobre el terreno evitando los obstáculos y tener variaciones de velocidad.

Este objeto estático representa un pequeño dron ISR de tipo ala volante con catapulta, a fin de familiarizar al alumno con las distintas formas en que se presentan los drones en la actualidad.

Dron ISR

Este avión de carga está presente en el mapa Airbase. Estático permite al usuario usarlo como objetivo de reconocimiento o blanco de ataque pero a la vez el usuario puede acercarse caminando hasta el mismo e incluso subirse a su bodega de carga.

PÁGINA 162 Solo en el mapa Airbase

Solo en el mapa Airbase El avión vuela, permitiendo reconocer el sonido gracias al audio 3D, además porta y lanza de manera aleatoria drones interceptores. Su función es proporcionar un realismo mayor del escenario

Gran Caravan

Puede ser manipulado con el teclado para posicionarlo en diferentes zonas del terreno (con Teleport) Su función es la familiarización con nuevas tecnologías, y su inclusión inicial permitía llevar objetos a diferentes zonas.

ULTV (Ultraliviano)

UGV traslado de heridos

Puede ser manipulado con el teclado para posicionarlo en diferentes zonas del terreno Su función es la familiarización con nuevas tecnologías No se debe interpretar como un simulador, solo es un prop dentro del mundo de SimDron El modelo humano es básico tipo maniquí para no sobrecargar el sistema

Puede ser manipulado con el teclado para posicionarlo en diferentes zonas del terreno Su función es la familiarización con nuevas tecnologías Aunque puede ser manipulado con el teclado no se debe interpretar como un simulador, solo es un prop dentro del mundo de SimDron

UGV logístico

Tiene interior por lo que el usuario puede subirse al mismo, solo está en la escena de montaje de manera estática. Además del interior se representa las jaulas antidrones alrededor para que el alumno comprenda las dificultades visuales de este tipo de adiciones en un entorno de combate.
