PÁGINA 38 Configuración Gráfica

Configuración Gráfica

Puede acceder a la escena de manual en cualquier momento a través del icono en la pantalla principal SimDRON permite ajustar la calidad gráfica para adaptar el funcionamiento del simulador al rendimiento disponible en el visor Meta Quest. La aplicación se entrega configurada de fábrica con el ajuste recomendado para el dispositivo, por lo que normalmente no es necesario modificar estos valores.

Desde esta pantalla pueden seleccionarse los perfiles Muy Bajo, Bajo, Medio, Alto, Muy Alto o Custom. Los perfiles predefinidos modifican automáticamente parámetros como la calidad y distancia de las sombras, el nivel de detalle del terreno y la representación de la vegetación.

El modo Custom permite realizar ajustes individuales. Se recomienda utilizarlo únicamente cuando sea necesario corregir problemas de rendimiento o cuando se requiera una configuración específica para una instalación determinada.

Durante el uso, SimDRON supervisa el rendimiento y el estado térmico del visor. Si detecta una condición que pueda afectar la estabilidad, puede reducir temporalmente algunos parámetros gráficos para favorecer un funcionamiento fluido.

Recomendación: mantener el perfil entregado por defecto. Si se observan caídas frecuentes de rendimiento, calentamiento excesivo o se desea modificar la configuración para un uso particular, se recomienda consultar previamente con el desarrollador.
