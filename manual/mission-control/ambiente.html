PÁGINA 32 Ambiente

Ambiente

Controla las condiciones generales del mundo virtual. Permite así que todos compartan hora, cielo, luz, clima, viento APLICAR A AULA Publica las condiciones actuales a los dispositivos correspondientes. BLOQUEAR CONTROLES Impide modificaciones accidentales una vez comenzada la actividad. SKYBOX COMÚN DEL AULA Galería visual de cielos. Hora Puede alterar:

iluminación; tono ambiental; contexto de misión. Clima Según el escenario puede representar:

cielo despejado; nubosidad; lluvia; tormenta; niebla; condiciones invernales. Viento Variable especialmente relevante para ejercicios de vuelo. Puede utilizarse para aumentar progresivamente la dificultad. METOC Capa de información meteorológica resumida.
