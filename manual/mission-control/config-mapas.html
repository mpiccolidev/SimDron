PÁGINA 47 Config

Config

Es la configuración general de la visualización del mapa

Coordenadas Las coordenadas se pueden setear de manera posX / posZ o MGRS local, actualmente la telemetría de SimDron maneja las primeras y luego hace la conversión, pero archivos históricos pueden estar aún con el MGRS simulado sin convertir

Pintar Por Se puede poner por Drone, por altura o por velocidad. Eso cambia el color de la línea de trazo del dron Mapas Se pueden visualizar en 2D lo cual es más compatible con la información gráfica y 3D que sirve para visualizar accidentes del terreno

Los mapas propios de SimDron ya están cargados, además se pueden añadir mapas por PNG y GLB

PÁGINA 49 Mapas de SimDron

Mapas de SimDron

Mapa Mountain en vista 2D, con - y + del viewport se ajusta el zoom. En la vista 2D se puede ver más apagado con el slider “fondo” cuando se necesita ver con más claridad los elementos gráficos

Mapa FOB en vista 3D El mapa se puede girar con la mano pero esto hace perder la sincronización con los elementos gráficos, para tal caso utilizar el slider “giro”

PÁGINA 50 Material de referencia

Si bien SimDron funciona de manera automática si está el hub en live y los dispositivos conectado. También podemos cargar csv de ejercicios individuales anteriores o incluso generar los propios (por ejemplo usando IA para rellenar los campos)

Estos datos de vuelo podemos verlos en 2D o 3D. En el caso de 3D podemos usar el slider “altura” para ajustar la proporción
