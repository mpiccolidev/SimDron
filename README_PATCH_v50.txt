SimDron Web v5.0 — Tactical UX / Information Hierarchy
========================================================

OBJETIVO
Mejorar legibilidad y organización sin cambiar el contenido ni el posicionamiento general de la web.
La capa rápida sigue siendo sobria; la profundidad técnica queda más clara y más fácil de explorar.

REEMPLAZAR EN LA RAÍZ
- index.html
- styles.css
- script.js

NO AGREGA ASSETS NUEVOS
Reutiliza las imágenes que ya fueron subidas en v4.7, v4.8 y v4.9.

CAMBIOS
- Botones de módulos y submódulos más grandes y claramente interactivos.
- Datos estáticos (10 visores, LAN, etc.) visualmente distintos de los botones.
- Línea animada de flujo de datos en paneles técnicos (CSS, costo mínimo).
- Galerías técnicas con imagen principal mucho más grande.
- Visor de imágenes en overlay con anterior/siguiente y teclado.
- Preview principal de mapas ampliable en overlay.
- SYSTEM pasa de 4 columnas estrechas a 2x2 en desktop; expansión de arriba hacia abajo.
- SENSOR & ISR STACK ahora es un explorador interactivo RGB / SRR / THERMAL / TRACK.
- Tipografía y espaciado aumentados en PC para lectura técnica.
- No toca demostrador 3D, mapas fuente, videos ni assets.
- No toca title, meta description, canonical ni configuración SEO.

SUBIDA
GitHub -> Add file -> Upload files -> reemplazar los tres archivos -> Commit changes.
Luego esperar GitHub Pages y hacer Ctrl+F5.
