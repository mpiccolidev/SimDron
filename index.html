01 / SYSTEM

UN ENTORNO SINTÉTICO PARA REPRESENTAR VUELO, PLATAFORMA Y MISIÓN.

SimDron es una plataforma de simulación basada en realidad virtual, físicas de vuelo y entornos 3D interactivos. El sistema permite recrear diferentes condiciones de vuelo, configuraciones de aeronave, escenarios geográficos y situaciones operativas dentro de una misma experiencia inmersiva.

03 / FLIGHT CONTROL DEMONSTRATOR

MODE 2. CONTROLES VISIBLES. COMPORTAMIENTO COMPARABLE.

Una demostración interactiva simplificada permite comparar la lógica de control de ACRO, ANGLE y HORIZON utilizando el mismo esquema Mode 2 del simulador.

STICK L W / S — THROTTLE A / D — YAW
STICK R ↑ / ↓ — PITCH ← / → — ROLL
ACRO

El mando actúa sobre tasas de rotación. Sin auto-nivelado.

ANGLE

La aeronave se inclina para trasladarse y la inclinación reduce el componente vertical del empuje.

HORIZON

Traslación similar a ANGLE con compensación vertical para mantener altura según el mando de throttle.

MISSION AUTHORING / AAR

DISEÑAR, EJECUTAR Y REVISAR MISIONES COMPLEJAS.

Mission Control permite construir ejercicios para varios alumnos sobre un mismo entorno operacional, combinar múltiples blancos, rutas, eventos y contramedidas electrónicas activas y conducir la sesión desde una estación de instructor.

Durante el ejercicio se registran posiciones, estados y eventos relevantes para reconstruir la sesión y generar un feedback útil en la revisión posterior con los alumnos.

DEVELOPMENT CONTEXT

SimDron en CYS

SimDron fue desarrollado en el ámbito de Comunicación y Sistemas S.A. (CYS). El desarrollo técnico principal y la ejecución directa de las áreas que se detallan a continuación corresponden a Mauro Iván Piccoli: software, arquitectura, XR, simulación, Mission Control, arte técnico, UI/UX, optimización y documentación.

USO Y ALCANCE

SimDron es una herramienta de simulación con fines educativos y de entrenamiento. La simulación no reemplaza la operación real, los procedimientos aplicables ni las recomendaciones de seguridad de los dispositivos de realidad virtual utilizados.
